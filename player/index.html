Play an Express simulation

Every Express simulation is a single self-contained JSON file (view + css + js). This player embeds an open-source implementation of the USF runtime, so the sims run entirely in your browser — no backend, no account, no network calls.

Pick one from the catalog above, drag & drop a .json anywhere on this page, or use Open JSON.
